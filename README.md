# Joel Smith's Personal Portfolio Website

A clean, professional portfolio website showcasing resume, projects, and personal information.

## 🌟 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Smooth Navigation**: Clean navigation with smooth scrolling between sections
- **Professional Layout**: Well-organized sections for About, Resume, Projects, and Contact
- **Beginner-Friendly**: Built with vanilla HTML, CSS, and JavaScript - easy to understand and customize
- **Modern Styling**: Clean design with subtle animations and hover effects

## 📁 File Structure

```
/
├── index.html          # Main webpage
├── styles.css          # All styling and visual design
├── script.js           # Interactive features and animations
├── GETTING_STARTED.md  # Detailed customization guide
└── README.md           # This file
```

## 🚀 Quick Start

1. **View the website**: Open `index.html` in your web browser
2. **Customize content**: Follow the `GETTING_STARTED.md` guide
3. **Make it yours**: Replace placeholder content with your information

## 📝 Sections Included

- **Hero Section**: Eye-catching introduction with your name and tagline
- **About Me**: Personal story and background information
- **Resume**: Education, experience, and skills
- **Projects**: Showcase your work with links and descriptions
- **Contact**: Ways for people to reach you

## 🎨 Customization

The website is designed to be easily customizable:

- **Colors**: Change the color scheme by updating CSS variables
- **Content**: Replace all placeholder text with your information
- **Images**: Add your photos and project screenshots
- **Sections**: Add new sections or modify existing ones

See `GETTING_STARTED.md` for detailed instructions.

## 📱 Responsive Design

The website automatically adapts to different screen sizes:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (up to 767px)

## 🔧 Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Modern styling with Grid, Flexbox, and animations
- **Vanilla JavaScript**: Interactive features without dependencies

- **Traditional hosting**: Upload files via FTP
